# 功能简介

IDE Electron 是一个面向 Windows 本地开发工作流的桌面 IDE，将项目管理、代码浏览、Git 操作、AI 工具和文档阅读集中在一个应用中。

## 项目管理

添加、移除和切换本地项目，并保存最近打开记录。

## 代码工作区

通过文件树浏览项目文件，使用代码编辑器修改代码，并预览 Markdown 文档。

## Git 工作流

查看项目状态，执行常用的 Git 操作，减少在多个工具之间切换。

## AI Runtime

管理 Codex、Claude 等本地 AI CLI，配置项目使用的 Runtime，并查看运行状态。

## AI Gateway

集中管理 AI Provider、模型路由和 Codex 连接配置。

## 会话记录

导入、查看和管理 AI CLI 会话记录，支持 Markdown 内容预览和整理。

## 学习中心

管理学习内容与技能，并使用浏览器辅助能力记录和整理资料。

## Markdown 工作区

直接打开 Markdown 文件，支持 GFM、代码高亮、Mermaid 和表格预览。

## 浏览器截图

捕获网页内容，处理固定元素，并在独立窗口中预览或保存截图。

## Windows 集成

支持 Markdown 文件关联和 Windows 安装包发布。
